#  Pizzaria Baixada Fluminense
https://melhorpizzariabaixadafluminense.netlify.app/

Site institucional desenvolvido para a Pizzaria Baixada Fluminense, com foco em apresentar o cardápio, facilitar o contato com clientes e oferecer uma experiência moderna e responsiva em qualquer dispositivo.

##  Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

##  Funcionalidades

* Design responsivo
* Interface moderna e intuitiva
* Seção de cardápio
* Informações de contato
* Integração com WhatsApp
* Navegação otimizada para dispositivos móveis

##  Responsividade

O projeto foi desenvolvido para funcionar perfeitamente em:

* Smartphones
* Tablets
* Notebooks
* Computadores Desktop

## 📂 Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
```

2. Abra o arquivo `index.html` no navegador.
